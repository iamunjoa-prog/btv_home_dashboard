구글 시트 연동 설정
Sheet ID 1개로 탭 5개를 모두 불러옵니다. 탭 이름이 바뀐 경우 수정해주세요.

시트를 처음 연동하는 경우

  1. 구글 시트 → 파일 → 공유 → 웹에 게시
  2. 형식 쉼표로 구분된 값(.csv) → 게시
  3. 아래 Sheet ID 확인 후 연동하기
탭 이름 (변경 시만 수정)
P1 홈 전체
P2 이벤트 탭
P2 콘텐츠 탭
P3 콘텐츠 블록 (raw)
🔧 관리자 모드 — 블록/배너 분류 규칙
분류 규칙은 구글 시트 대시보드_설정 탭에서 관리합니다. 시트 수정 후 대시보드를 새로고침하면 모든 사용자에게 즉시 반영됩니다.
📋 시트 구조
A: 분류유형 (block / banner)
B: key (고유값, 영문)
C: label (표시명)
D: color (색상 코드, 예: #3B5BDB)
E: include (포함 키워드, | 로 구분)
F: exclude (제외 키워드, | 로 구분)
💡 block 분류: include 있는 규칙 먼저 매칭 → include 없는 규칙이 기본값(나머지 전부)
💡 banner 분류: include 키워드 매칭 순서대로 적용
💡 배너로 분류된 블록은 콘텐츠 블록 실적에서 자동 제외
💡 일반 분류 제외 키워드에 걸린 블록 → Today B tv > 하위버전 탭
